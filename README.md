# Apoio Digital

Site mobile-first para inserir uma foto na matriz de apoio e exportar PNG em 1080 × 1440 px.

## Uso

1. Coloque a matriz original em `public/assets/matriz-apoio-digital.png`.
2. Instale dependências com `npm install`.
3. Execute `npm run dev` para desenvolvimento.
4. Gere a versão de produção com `npm run build` e visualize com `npm run preview`.

Todo o processamento ocorre no navegador; nenhuma foto é enviada a servidor.
